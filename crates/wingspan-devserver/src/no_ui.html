Wingspan is running — without the UI

This binary was built without the embed-ui feature, so it serves the API at /api/v1 and nothing else.

Develop against it

export NVM_DIR="$HOME/.nvm" && . "$NVM_DIR/nvm.sh"
cd web && npm ci && npm run dev

Vite serves the app on http://localhost:5173 and proxies /api back to this process.

This binary is dev-only. The product is the Wingspan desktop app, packaged as the .deb just bundle builds.
